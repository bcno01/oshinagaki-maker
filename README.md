# お品書きメーカー

即売会(同人誌即売会・マルシェなど)向けのお品書き作成ツールです。商品の写真と価格を登録するだけで、自動でレイアウトされたお品書き画像を作成できます。イベント当日は「販売モード」に切り替えて、タッチ操作でのレジ・在庫管理としても使えます。

## 使い方

### 1. 商品タブ

- 上部の「サークル名未設定」をタップ(またはヘッダーの ⚙️)して、イベント名・参加日程・サークル名・配置番号を入力する
- 同じ画面の「表示通貨」で日本円(¥)・韓国ウォン(₩)を切り替えられる(商品一覧・お品書き画像・販売モードの価格表示すべてに反映される)
- 「+ 商品を追加」で商品を登録し、サムネイルをタップして写真を選択する
- 商品名・価格・在庫数(空欄で無制限)を入力する
- 「☆メイン」をタップすると、お品書きでその商品が大きく表示される(複数選択可)
- ↑↓ボタンで表示順を並び替え、削除ボタンで商品を削除できる

### 2. お品書きタブ

- 登録した商品からお品書き画像が自動生成される(メイン商品は大きく、他は自動でグリッドに敷き詰められる)
- 「配置を提案」に2種類のレイアウト案(標準グリッド/均等グリッド)、「配色を提案」に6種類の配色案(クラフト/レンガ/オリーブ/プラム/マスタード/インディゴ)が実際の商品データでサムネイル表示され、タップするだけで切り替えられる
- フォント(明朝 / ゴシック / 丸ゴシック)を自由に変更できる
- 保存形式をPNG(高画質)かJPG(軽量・共有向け)から選べる。画像は1920×1080px(横長)で書き出される
- 「画像として保存 / 共有」で選んだ形式の画像として保存、対応端末では共有シートから直接SNS投稿やAirDropもできる

### 3. 販売モード

- 商品がタイル状に並び、タップするとカートに追加される(タップごとに数量が増える)
- 在庫を設定している商品は残数が表示され、0になると自動的にタップできなくなる
- 「会計する」を押すと在庫が確定で減算され、売上履歴に記録される
- 「履歴を見る」で会計履歴と合計売上を確認できる。誤タップ時は各履歴の「取り消す」で在庫を戻せる
- サークル情報の編集画面で「販売モードのロックPIN」(4桁)を設定すると、販売モード中は他のタブ・サークル情報の編集ができなくなる(お客さんに端末を渡す際の誤操作・タブ移動防止)。右上の🔒アイコンからPINを入力すると解除できる。PINを空欄のままにすればロックなしで従来通り使える

## インストール(PWA)

- **Safari(iPhone/iPad)**: 共有メニュー →「ホーム画面に追加」
- **Safari(Mac)**: 共有メニュー →「Dockに追加」

## 技術構成

- 素のHTML/CSS/JavaScript(ビルド不要)
- すべてブラウザ内で完結(商品データ・写真・売上履歴はすべて端末の localStorage に保存。サーバー送信なし)
- Canvas API でお品書き画像を自動レイアウト・生成(簡易ビンパッキングでメイン商品を2×2、通常商品を1×1として敷き詰め)。紙質感のグレインテクスチャとスタンプ風バッジを描画
- Web Share API 対応端末では画像を直接共有、非対応時はダウンロード
- Service Workerでアプリ本体をキャッシュ(`sw.js`)
- GitHub Actionsで`main`ブランチへのpush時に自動デプロイ(`.github/workflows/pages.yml`)

## 注意

- 商品データ・写真・売上履歴はブラウザのlocalStorageに保存されます。ブラウザのデータを消去すると失われるため、必要に応じてお品書き画像をこまめに保存してください。
- 端末のストレージ上限により、大量の高解像度写真を登録すると保存に失敗する場合があります(写真は自動で長辺900px程度に圧縮されます)。
